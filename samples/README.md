# Sample books

Small books for checking Vach on a real phone. Generated by
`node scripts/samples/gen-samples.mjs`, `node scripts/samples/gen-images-sample.mjs` and `node scripts/samples/gen-docx-samples.mjs` (deterministic - rerunning gives the same bytes).

| File | What it is for |
| :-- | :-- |
| `tables-sample.epub` | Every table shape Vach adapts: narrow 2-column, 5-column, 9-column with a header, headerless, colspan/rowspan, nested, row headers, a LitRPG stat sheet, a publisher-styled table (fixed widths, white cells, nowrap), plus a long unbroken URL, a long code line and a long identifier. Nothing should ever scroll sideways. |
| `devanagari-sample.epub` | The title "वाच", Marathi, Hindi and Sanskrit paragraphs (conjuncts, nukta, candra-o, Vedic accents, digits), and math, arrow and currency symbols. Nothing should show as a box. |
| `images-sample.epub` | A 4000 x 6000 poster, a wide map, a tall panel, a tiny inline icon (tapping it must not open anything), an image with no width/height, a white-background black-line diagram (night theme: tap it, "Invert"), an SVG with a viewBox, an animated GIF (must keep moving) and a transparent PNG. Nothing may jump while images load, nothing may be clipped, stretched or wider than the page, and tapping a picture opens the lightbox (pinch, double-tap, drag, swipe down, Back). 78 KB because the big images are flat colour. |
| `docx-sample.docx` | A Word document (6 KB): text before the first heading, Heading 1-3 (Contents shows them nested), bold-only lines that are *not* headings, bulleted and numbered lists, a simple table, a 9-column table (adapts on a phone), a table with merged cells, a 600 x 400 picture (tap it to zoom), a footnote and an endnote (tap the numbers: they jump to the notes and the notes' arrows jump back), and cross-references. Shows a DOCX badge in the library. |
| `docx-no-headings.docx` | About 20,000 words with no heading styles at all: Vach cuts it into "Section 1..8" of about 2,750 words, with those in the Contents. |
